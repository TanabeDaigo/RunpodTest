# metrojs

#### 開発環境構築

```
# PowerShellを管理者権限で開き、クローンしたフォルダに移動後、下記コマンドを実行してください。
.\tools\setup.bat

# コマンドプロンプトを開き、ルートフォルダにあるstart.batを起動し、下記コマンドを実行
pnpm install

# 開発モードで起動
 pnpm run dev

# 下記URLでアクセスする
http://localhost:3000/

■本番モードでコンパイルと起動
pnpm run start:prod
このコマンドだと毎度クリーン＆ビルドするので、一度ビルドしたあとは npm run startでOK
# 下記URLでアクセスする
http://localhost:3020/
```

## 開発コマンド

### 開発サーバーの起動

```bash
pnpm run dev
```

開発モードでサーバーを起動します。ホットリロードが有効で、コードの変更がリアルタイムで反映されます。

### テストの実行

```bash
npm run test
```

ユニットテストと統合テストを実行します。Jestを使用して、すべてのテストファイルを実行し、結果を表示します。

### キャッシュのクリア

```bash
pnpm run clear
```

ビルドキャッシュと一時ファイルを削除します。ビルドの問題が発生した場合に使用してください。

### 依存関係のクリーンインストール

```bash
pnpm run clean-install
```

`node_modules`を削除し、依存関係を新規インストールします。依存関係の問題が発生した場合に使用してください。

### 開発サーバーの起動（本番モード）

```bash
pnpm run start
pnpm run start:staging ・・・検証環境
```

本番モードでサーバーを起動します。最適化された設定でアプリケーションを実行します。

### プロジェクトのビルド

```bash
pnpm run build
```

プロジェクトを本番用にビルドします。コンパイル、アセットの最適化、バンドルの生成を行います。

### 本番環境での起動

```bash
pnpm run start:prod
```

本番環境用の最適化されたビルドを使用してサーバーを起動します。本番環境でのデプロイ時に使用します。

### ソースマップ付きでの起動

```bash
cd ./apps/webapp
pnpm run start:sourcemap   ・・・本番環境でのソースマップ起動
pnpm run start:staging:sourcemap ・・・検証環境でのソースマップ起動
```

ソースマップを有効にしてアプリケーションを起動します。これにより、本番/検証環境でのデバッグが容易になります。

主な機能:

- 本番環境のコードを元のソースコードにマッピング
- エラー発生時の正確な行番号の特定が可能
- デバッグツールでのソースコード表示
- パフォーマンスプロファイリングの詳細な分析

※ソースマップの有効化により、若干のパフォーマンスオーバーヘッドが発生する可能性があります。
本番環境での使用は必要な場合のみにすることを推奨します。
